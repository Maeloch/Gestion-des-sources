Import

Reconnaît deux formats : le fichier d'inventaire Excel historique (feuilles "Sources scellées", "Sources non scellées", "Sources consommables") ou un fichier déjà exporté par cette application (feuille "Sources"). Par défaut, une source déjà présente (même identifiant) est ignorée, pas écrasée : l'import peut être relancé sans risque. Beaucoup de colonnes du fichier n'ont pas d'équivalent direct dans l'application ; elles sont regroupées dans le champ "Commentaire" de chaque source pour ne rien perdre. Chaque import est tracé dans l'audit.

Utile pour corriger une erreur : exporter les sources, corriger le fichier obtenu à la main, cocher cette case, puis réimporter ce fichier corrigé. Les radionucléides déjà associés à une source ne sont jamais modifiés par cette option (seuls les champs de la source elle-même le sont), pour ne pas risquer d'en créer des doublons.
